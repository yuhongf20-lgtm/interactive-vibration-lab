# 互動式振動與旋轉機械模擬實驗室

以 TypeScript、Vite 和 Chart.js 製作的靜態教學網站。使用 Node.js 22.12 以上版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## 實驗操作

- **自然頻率**：先保存參考組，再分別增加質量或剛度，比較波形與頻率讀值。以 2 kg 和 200 N/m 為例，ωₙ = 10 rad/s，fₙ ≈ 1.592 Hz，Tₙ ≈ 0.628 s。質量加倍後，fₙ 變為原值的 1/√2。
- **自由振動與阻尼比較**：設定初始位移、速度及時間，播放或拖曳時間軸。阻尼比較的各曲線共用質量、剛度及初始條件，可點擊圖例切換顯示。
- **受迫振動與共振**：用低頻、接近共振及高頻切換觀察位移。預設頻率會限制在 0.1–10 Hz。激振頻率可用數字欄輸入比滑桿更細的數值。力與位移分圖，頻率響應圖以 r = ω/ωₙ 標示工作點。固定力的共振峰在 ζ < 1/√2 時位於 r = √(1−2ζ²)。正阻尼可降低峰值。
- **頻率響應**：柔度為 H = 1/(k−mω²+i cω)，圖表顯示其幅值（m/N）。無阻尼奇點以缺值表示。
- **旋轉機械偏心**：先設定一根桿件的總質量、長度、半徑、轉速與支撐。移動「質量分布均勻程度」滑桿或點比較表中的四種分布，觀察同一根桿件的質心如何偏移。100% 為完全均勻，0% 為此模型的最大密度對比。暖色代表較密，集中方向以截面 +x 為 0°、朝 +y 為正向。O 是幾何軸心，G 是由 128 個元素重新計算的整體質心。
- **讀取轉子結果**：拖曳時間軸同步查看桿件、旋轉截面、x(t)、y(t) 與軸心軌跡。動畫旁列出位移倍率。表格的振幅 A、峰對峰 2A 和 RMS = A/√2 皆為單軸穩態值。圖 A 固定轉速，比較偏心距。圖 B 固定目前質量分布，掃描 0–3000 rpm。完整時間響應保留初始位移，理論穩態模式顯示正弦特解。無阻尼精確共振時顯示有限時間響應，穩態值留空。

## 振動學互動講義

從導覽列選「互動講義」。01～14 依專案根目錄的《振動學助教講義_詳細概念與逐步計算_7頁版.docx》順序整理為網頁。可修改例題已知條件、查看逐步代入與 SVG，並從每個單元開啟對應實驗。再次選「互動講義」會回到剛才的單元與閱讀位置，也可用網址片段如 `#handout/08` 直接開啟單元。手機版採單欄。第 14 單元另有合成訊號實驗，可調轉速及倍頻振幅，觀察時間波形和離散傅立葉分析結果。

15 是擴充單元。調整同一根桿件的質量分布，會同步更新質心、偏心距、不平衡力、位移及軌跡，並對照偏心距與轉速的振幅曲線。模型描述靜態不平衡，軸向偶不平衡需要能處理力矩的轉子模型。資料與例題在 `src/lesson-text.ts`、`src/lesson-math.ts`。Word 可作為維護來源，建置後的網站只需要 dist 中的網頁與資產。

使用 Python 預覽前先重新建置，然後開啟 `http://localhost:8000/#handout`。

## 模型、輸出及限制

採線性平移單自由度模型 m x″ + c x′ + kx = F₀ sin(ωt)，轉子另採二維剛體平移模型，兩個橫向方向各以 M、k、c 求解。只有桿件參與平移，因此等效運動質量取桿件質量 M。密度分布沿軸向一致，桿長在固定質量及半徑下會改變平均密度，橫向一階質量矩維持相同。自由響應依阻尼情況使用封閉解，有激振時用 RK4。有限穩態振幅 X = F₀/√((k−mω²)²+(cω)²)，相位角以 atan2 表示位移落後角。無阻尼精確共振只顯示有限時間響應，頻率掃描的奇點留空。轉速區帶為教學觀察範圍，模型省略轉軸彎曲、軸承非線性及多自由度效應。

時間圖、播放游標、動畫及 CSV 共用同一份模擬資料。圖表會抽樣，動畫對位移採視覺縮放。CSV 欄名含單位。各圖表可下載 PNG。理論穩態只顯示正弦特解，完整響應保留初始條件的影響。

## 使用 Python 預覽或可攜式 Node.js 建置

Python 靜態伺服器只能提供已建置的頁面。修改 `src/` 後，先執行 `npm run build` 更新 `dist/`，再重新整理瀏覽器。既有 Python 伺服器可繼續使用。

```powershell
py -m http.server 8000 --directory dist
```

開啟 `http://localhost:8000/#rotor`。Windows 可從 [Node.js 下載頁](https://nodejs.org/en/download)取得 22.12 以上的 Windows ZIP，解壓縮後在 VS Code 的 PowerShell 終端機用實際路徑取代下方範例。這段 PATH 只在目前終端機生效。

```powershell
$env:Path = "C:\tools\node-v22.16.0-win-x64;$env:Path"
npm.cmd ci
npm.cmd test
npm.cmd run build
```
